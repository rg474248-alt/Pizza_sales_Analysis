🍕 Pizza Sales Data Analysis using SQL
📌 Project Overview

This project focuses on analyzing pizza sales data using SQL to understand business performance, customer ordering patterns, revenue, and product performance.

🎯 Business Questions Answered

🔹 What is the total number of orders?

🔹 What is the total revenue generated?

🔹 Which pizza has the highest price?

🔹 Which pizza size is ordered the most?

🔹 What are the top 5 most ordered pizza types?

🔹 Which pizza categories have the highest quantity ordered?

🔹 What are the busiest hours for pizza orders?

🔹 What is the average number of pizzas ordered per day?

🔹 Which pizzas generate the highest revenue?

🔹 What percentage does each pizza contribute to total revenue?

🔹 How does revenue grow over time?

🔹 What are the top 3 revenue-generating pizzas in each category?

🛠️ SQL Skills Used
JOINs
Aggregate Functions
GROUP BY
ORDER BY
CTEs
Subqueries
Window Functions
RANK()
PARTITION BY
Date and Time Functions
Cumulative Revenue Analysis
📊 Business Value

This analysis helps businesses understand:

Customer ordering behaviour
Best-selling products
Revenue-generating pizzas
Peak ordering hours
Category performance
Sales trends over time

These insights can help a pizza business make better decisions related to inventory, marketing, product strategy, and sales performance.
